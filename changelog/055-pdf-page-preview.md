# 055 图转 PDF 先预览再导出

**日期：** 2026-10-27

## 背景 / 问题

图转 PDF 放入图片后只显示文件名。点生成才会把每张图按像素尺寸铺成白底 JPEG 并立刻下载，导出前看不到页面、不能调顺序，也不能选纸张。

## 变更内容

- 放入图片后显示当前页和全部页面的缩略图。纸张、方向、放入方式、页边距、底色、旋转和顺序都会更新这块预览。
- 默认 A4，方向随图片。另有 A3、A5、Letter 和原比例。原比例与图片同形，长边为 297 毫米。
- 缩略图可拖动排序，也可以前移、后移、移除和继续添加。
- 导出使用同一套页面几何，按 150 DPI 写入 JPEG，长边不超过 4096 像素。文件名改用第一张图片的主文件名。

## 数据库与兼容性

- 无数据变化。
- 仍在浏览器本地生成，不上传。默认页面从「图片像素等于 PDF 点」改为 A4；原比例仍保留图片形状，但长边固定为 297 毫米。

## 验证

- `node --experimental-strip-types --test apps/web/src/utils/pdf-layout.test.ts`：通过。覆盖 A4 随图片方向、强制纵向与页边距、铺满裁切、拉伸、原比例和 150 DPI 导出像素。
- `npm run typecheck`：通过。
- 已有开发服务 `127.0.0.1:13175`。用 960×480 和 480×960 两张样例图核对：
  - 横图预览为横向 A4，页码显示 `297 × 210 mm`，画面上下留白，中间是原图颜色。
  - 第二页竖图为 `210 × 297 mm`。强制纵向后，横图也变成 `210 × 297 mm`。
  - 页边距拖到 12% 后，标签和预览一起变。
  - 后移后，当前页跟着这张图到第 2 页，画面仍是原来的横图。
  - 生成的 PDF 有 2 页。强制纵向时两页都是 595.28 × 841.89 点，文件名用第一张图的主文件名。
  - 1440×900 的暗色和亮色都能看清纸张、缩略图和底色色块。390×844 不横向溢出，预览在上，缩略图横排在下。
- 浏览器控制台没有错误。测试读像素时出现一次 Canvas2D readback 警告，页面自己不读像素。
