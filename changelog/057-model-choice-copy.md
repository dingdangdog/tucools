# 057 模型包说明不再让人回到当前网页

**日期：** 2026-10-27

## 背景 / 问题

抠图、优化、消除不可用时，「下载模型」写着：模型包要单独下载，解压到说明中的目录后，再回到这里检查。

打开官网的人没有可写的模型目录。模型包是自己部署 Docker 或安装客户端之后，放到那一次部署里的。这句话把网页当成了存放位置。

## 变更内容

- 各语言的「下载模型」说明改为：先自己部署或安装，再把模型包放到那一次部署的模型目录。当前网页放不了模型。
- 客户端里这一项仍是「下载并安装」，不使用这句说明。

## 影响范围

- `apps/web/src/content/` 各语言文案

## 数据库与兼容性

- 无数据库影响。
- 三个入口和链接不变。引擎健康检查不变。

## 验证

- `npm run typecheck` 通过。
- 未启动页面服务，未在浏览器打开抠图页核对这句话。
