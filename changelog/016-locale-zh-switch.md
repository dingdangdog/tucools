# 016 切回简体中文时不再跳回上一种语言

**日期：** 2026-10-24

## 背景 / 问题

从其他语言再选简体中文时，页面没有变化。简体中文使用不带前缀的根地址。进入 `/` 时，路由先读取上一次保存的语言；语言菜单当时还没写入新选择，于是又跳回刚才的语言。带前缀的语言不会进入这条根地址跳转。

## 变更内容

- 语言菜单在切换地址前先把所选语言写入 `tucools-locale`。
- 根地址仍然只在打开 `/` 时采用已保存语言。直接打开 `/` 且保存的是其他语言时，仍会进入该语言。

## 影响范围

- `apps/web/src/components/LocaleSelect.vue`
- `apps/web/src/router.ts`

## 数据库与兼容性

- 无数据库影响。
- 已有中文地址和其他语言前缀不变。

## 验证

- `npm run typecheck`：通过。
- 未启动开发服务器，未在浏览器里从其他语言切回简体中文。
