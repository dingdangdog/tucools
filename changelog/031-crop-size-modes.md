# 031 裁剪只收尺寸类

**日期：** 2026-10-26

## 背景 / 问题

030 把切图放进了裁剪。切图是把一张图拆成多块，和裁进指定尺寸不是同一类。证件照、社交尺寸、应用商店尺寸才是把画面放进目标尺寸。

## 变更内容

- 裁剪的二级地址改为 `/cropping`、`/id-photo`、`/sizes`、`/store`、`/tocircle`。
- 切图回到侧栏和首页的独立项，地址仍是 `/cutting`。
- 圆形仍留在裁剪里。它是按直径裁掉画面，不是拆成多块。

## 影响范围

- `apps/web/src/nav.ts`、`content/` 各语言的裁剪说明
- `docs/deploy.md`、`AGENTS.md`

## 数据库与兼容性

- 无数据库影响。地址不变。
- `TUCOOLS_FEATURES` 写出 `cropping` 时开放上述五个裁剪地址。`cutting` 仍单独控制切图。

## 验证

- `npm run typecheck`：通过。
- 已有开发服务 `http://127.0.0.1:13175/cropping`。切换为裁剪、证件照尺寸、社交尺寸、应用商店尺寸、圆形。侧栏另有切图，没有社交尺寸和应用商店尺寸。
- `/sizes`、`/store` 打开后侧栏「裁剪」仍为当前项。`/cutting` 没有这排切换，当前项是「切图」。
