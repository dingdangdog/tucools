# 005 工作台界面

**日期：** 2026-10-24

## 背景 / 问题

工具页都是窄栏里的标题、下拉框和小虚线框。原桌面版是大预览加侧栏设置，EasyImage 是工具卡、选项芯片和带体积的结果。现有页面看不出图像工具该有的工作区。

## 变更内容

- 侧栏改为图标加名称，顶栏显示当前工具名。
- 首页改为带小色块图标和一句说明的工具卡。
- 单图工具改为画面区加右侧设置。抠图和优化完成后可拖动对比。消除的涂抹层对齐画面。水印和加字即时预览。裁剪增加常用比例。
- 批量工具改为上方设置、拉高的拖放区和带尺寸体积的结果卡。压缩显示原体积到新体积。
- 配色仍是石板亮色、中性黑暗色和蓝色强调。新增画面底、芯片和棋盘格令牌。
- 导航从 `router.ts` 移到 `nav.ts`。

## 影响范围

- `apps/web/src` 的外壳、页面、样式和文案
- `design/002-workspace-ui.md`
- `AGENTS.md` 中的导航和页面组件说明

## 数据库与兼容性

- 无数据库影响。
- 主题键 `tucools-theme` 不变。
- 路由和 `/api/engine` 参数不变。
- 水印、加字、证件照尺寸、社交尺寸改为一次处理一张，以便在画面上预览。Favicon 先显示结果，再打包下载。

## 验证

- `npm run typecheck`：通过。
- 浏览器核对首页、压缩、裁剪、水印、抠图空态、消除空态，以及亮色、暗色和 390px 窄屏。压缩用样图生成 `919 B → 1.1 KB · 120×80` 的结果卡。裁剪器和水印预览能显示。抠图页显示引擎可用、模型芯片，未选图时开始按钮禁用。
- 未点击系统保存对话框。未跑抠图、优化、消除推理。
