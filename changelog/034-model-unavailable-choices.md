# 034 模型不足时给出其他入口

**日期：** 2026-10-26

## 背景 / 问题

抠图、优化、消除在引擎无响应或没有可用模型时，画面上只有「这个功能暂时不能使用」。访客不知道可以自己部署、下载客户端或下载模型。

## 变更内容

- 这两种状态下，这句话下面列出三个入口：前往 GitHub 部署 Docker、下载客户端、下载模型。每条有说明和链接。
- 三个功能共用 `modelChoiceLinks`。当前是占位地址，正式链接确定后只改这一处。
- 设置区仍说明引擎无响应、缺哪些文件，以及模型包目录。原来的仓库和发布页两行链接改由这三个入口代替。
- 正在检查、功能可用、只缺部分模型时不显示这组入口。

## 影响范围

- `apps/web/src/release.ts`
- `apps/web/src/components/ModelChoices.vue`
- `apps/web/src/components/Stage.vue`
- `apps/web/src/components/EngineStatus.vue`
- `apps/web/src/pages/CutoutPage.vue`
- `apps/web/src/pages/EnhancePage.vue`
- `apps/web/src/pages/ErasePage.vue`
- `apps/web/src/content/` 各语言文案

## 数据库与兼容性

- 无数据库影响。
- 健康检查地址和引擎契约不变。
- 三个链接是占位地址，点开会离开图酷。

## 验证

- 改完文案和组件后，`npm run typecheck` 通过。
- 已打开正在运行的 http://127.0.0.1:13175 。引擎未响应。抠图、优化、消除都显示「这个功能暂时不能使用」和同一组三个链接，开始按钮保持禁用。压缩页仍是拖放选图，没有这组入口。暗色和亮色桌面都看过。
- 窄屏时虚线框会把第三条裁掉，已改成窄屏随内容增高。这次改完后页面开发服务因另一处收录文案不完整而无法再打开，窄屏改动未在浏览器里复查。
