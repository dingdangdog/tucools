# 053 信息页并列显示原图

**日期：** 2026-10-27

## 背景 / 问题

AI提示词提取和图片信息在读完文件后只留下文字，原图不出现。选中图片后，选图区收成固定高度，图标、说明和按钮在虚线框里没有内边距，按钮贴着边框。去除信息把处理前、重绘后和结果拆成上下两截，宽屏上原图和结果不能并列，图片还会被挤到下一行。

## 变更内容

- 已有结果时，选图区改为横向排列，并留出内边距，按钮不再贴着虚线边框。这个紧凑选图区也用于其他批量工具。
- AI提示词提取和图片信息在宽屏上把原图和读出的内容放在同一行。窄屏仍上下排列。
- 去除信息在宽屏上并列三列：原图、重绘结果、处理前和重绘后的信息。窄屏改为单列，不再两列后再把图片换行。

## 影响范围

- `apps/web/src/components/Stage.vue`
- `apps/web/src/pages/PromptPage.vue`
- `apps/web/src/pages/PixPage.vue`
- `apps/web/src/pages/ExifPage.vue`

## 数据库与兼容性

- 无数据变化。
- 读取、重绘和导出内容不变。离开页面时会释放预览地址。

## 验证

- `npm run typecheck`：通过。
- 已有开发服务 `127.0.0.1:13175`。用一张 800×600 的样例图核对：
  - AI提示词提取、图片信息在 1600px 宽屏上原图和文字同一行；390px 窄屏改为上下排列，页面不横向溢出。
  - 去除信息在 1600px 和 1280px 都是三列同一行，390px 改为一列。亮色下边框、文字和按钮仍可辨认。
  - 选中图片后，选择按钮距选图区上、下约 27px，距右侧约 21px。
  - 压缩页出结果后的紧凑选图区同样留有内边距，结果图仍在。
