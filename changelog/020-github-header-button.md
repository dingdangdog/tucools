# 020 页头 GitHub 按钮与其他按钮同高

**日期：** 2026-10-24

## 背景 / 问题

页头 GitHub 链接用了 44px 的方形按钮，比语言和主题按钮高。图标路径是手写的，看起来不是 GitHub 标记。

## 变更内容

- GitHub 链接改用普通 `.btn`，高度与页头其他按钮一致，图标仍是 16px。
- 图标改为 Octicons 的 `mark-github` 16px 路径。

## 影响范围

- `apps/web/src/components/AppShell.vue`

## 数据库与兼容性

- 无。链接地址不变。

## 验证
