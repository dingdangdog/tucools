# 020 选图区统一放到选项上面

**日期：** 2026-10-24

## 背景 / 问题

单图工具先显示拖放区，再显示选项。压缩、缩放、转格式、圆形、切图、商店尺寸这些带选项的批量页相反，选项在上、选图在下。同一产品里选图位置不固定。

## 变更内容

- 批量页顺序改为说明、选图、错误、选项、结果。选图放进 `BatchLayout` 的 `stage` 插槽，排在选项前面。
- 带选项的批量页使用固定高度选图区，避免空拖放区把选项挤出首屏。没有选项的批量页仍由拖放区占满剩余高度。
- 单图工具保持说明、画面、选项、按钮，选图本来就在上面。

## 影响范围

- `apps/web/src/components/BatchLayout.vue`
- `apps/web/src/components/Stage.vue`
- 全部批量工具页。
- `design/002-workspace-ui.md`、`design/007-tool-rail-ads.md`

## 数据库与兼容性

- 无数据库影响。
- 处理参数、引擎接口和结果数据不变。只调整页面上下顺序。

## 验证

- `npm run typecheck`：通过。
- 已有开发服务器 `127.0.0.1:13175`。核对压缩、应用商店尺寸、灰度、抠图的空态：选图都在选项上面。压缩在约 390px 窄屏下仍是选图在上、格式和质量在下。未上传图片，未核对出结果后的紧凑选图条。
