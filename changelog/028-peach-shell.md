# 028 参考 Peach 的界面外壳

**日期：** 2026-10-25

## 背景 / 问题

侧栏用整行蓝色表示当前项，首页是一排带色块的说明卡。画面区和筛选都不够突出，和图像工具的使用方式不贴。

## 变更内容

- 暗色改为近黑底、抬升表面和更亮的画面格；亮色改为浅灰底和白表面。主操作仍是蓝色。
- 当前导航改为浅色圆角条，图标用蓝色。主题、功能菜单和仓库移到侧栏底部。
- 宽屏可把侧栏收成图标栏，记在 `tucools-nav-rail`。窄屏仍是抽屉。
- 首页用分组药丸筛选，工具卡改为上图下文。设置芯片改为药丸，选中项用浅底和蓝色细环。
- 顶栏只保留当前页标题和语言。

## 影响范围

- `apps/web/src/styles.css`、`AppShell.vue`、`HomePage.vue`、`LocaleSelect.vue`、`ResultGrid.vue`、`stores/ui.ts`、`index.html`
- `apps/web/src/content/` 全部语言增加收起、展开和「全部」
- `design/009-peach-shell.md`、`AGENTS.md`

## 数据库与兼容性

- 无数据库影响。
- `tucools-theme` 不变。新增 `tucools-nav-rail`，没有该值时侧栏展开。
- 路由、工具参数和 `/api/engine` 不变。

## 验证

- `npm run typecheck`：通过。
- 浏览器核对暗色首页、分组筛选、侧栏收起、亮色首页、压缩页、抠图空态，以及 390px 下压缩页的单列布局和导航抽屉打开状态。语言菜单能展开。
- 未测试安装包和 Docker 里的同一份页面。未启动引擎，抠图页显示引擎没有响应。未逐项点完每种语言的长文案。
