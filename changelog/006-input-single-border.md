# 006 输入框只保留一条边框

**日期：** 2026-10-24

## 背景 / 问题

文本框、数字框和下列选择同时有 1px 内边框，以及 `:focus-visible` 向外偏移 2px 的焦点环。侧栏表单在 `overflow-y-auto` 里撑满宽度，左右两侧的环会被裁掉。Windows 原生控件外观还会再画一圈外框。

## 变更内容

- `.field-input` 关闭原生外观，只保留一条边框。
- 聚焦时改边框颜色，不再额外画外环。
- 下列选择补自定义箭头。颜色选择器只留色块和外层这一条边框。

## 影响范围

- `apps/web/src/styles.css`
- 使用 `.field-input` 的压缩、缩放、切图、圆形、水印、加字页面。

## 数据库与兼容性

- 无数据库影响。
- 数字框不再显示系统上下箭头，仍可键盘输入。
- 按钮、链接、滑块和复选框的焦点环不变。

## 验证

- 浏览器打开水印页：暗色和亮色下，未聚焦输入框只有一条边框；点击文字、字号和位置后，四边都是强调色边框，左右没有被裁切。
- 压缩页的最长边、目标大小同样只有一条边框。
- 未跑 `npm run typecheck` 和 `npm run build:web`。
