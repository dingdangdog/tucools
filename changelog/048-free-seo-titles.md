# 048 各语言标题和关键字都带上「免费」

**日期：** 2026-10-26

## 背景 / 问题

检索标题大多只有十个字左右，例如「在线缩放图片 · 图酷」。工具页关键字只有工具短名和品牌，没有「免费」。搜索里常见的是「免费压缩图片」「免费抠图」这类长问法。

## 变更内容

- 简体中文、繁体中文和英语的检索标题改成带搜索词的长标题，开头是「免费」。
- 其余语言如果原标题不够长，在标题前补上「免费」，再用该语言的关键字补到足够长度。功能菜单、版本页和未知地址同样处理。
- 每种语言、每个页面的 `keywords` 都以「免费」开头，并带上该工具的中文搜索词，例如免费抠图、免费压缩图片、免费证件照。
- 构建时检查：任一语言、任一页面的标题或关键字缺少「免费」，或标题正文过短，构建失败。

## 影响范围

- `apps/web/src/seo.ts`
- `apps/web/src/content/` 全部语言
- `apps/web/index.html`
- 页面里的工具短名不变，侧栏仍显示「压缩」「抠图」。变长的是浏览器标题、Open Graph、Twitter、预渲染正文和 Markdown 标题。

## 数据库与兼容性

- 无数据库变化。工具地址不变。
- 已有旧地址跳转不变。

## 验证

- `npm run typecheck`：通过。检查发生在标题连接符调整之前；该调整只改了补词用的逗号，未再跑类型检查。
- `npm run build:web`：通过。断言要求 11 种语言的每个页面（含功能菜单、版本页和未知地址）标题与关键字都含「免费」，且标题正文宽度不少于 52。
- 构建结果抽查：简体压缩页标题为「免费在线压缩图片工具，JPG、PNG、WebP按质量或体积压缩且不上传 · 图酷」，关键字以「免费, 免费压缩图片」开头。英语压缩页标题为「免费 Free online JPG, PNG and WebP image compressor with no upload · TuCools」，关键字含「免费」和「免费压缩图片」。德语、日语、西班牙语、阿拉伯语标题同样以「免费」开头。
- 未在浏览器里逐页打开。未启动开发服务器。

- 未改各页说明正文，只改了标题和关键字。
