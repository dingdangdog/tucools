# 030 裁剪恢复实时预览和大图

**日期：** 2026-10-26

## 背景 / 问题

裁剪页只保留了框选和导出。拖动选区时看不到裁剪结果，也不能点开大图。原先 easyimage 的裁剪用 `cropper-viewer` 跟着选区更新，再点击预览查看大图。

## 变更内容

- 裁剪页在选区旁边显示实时预览，选区、旋转和翻转会立刻反映到预览上。
- 点击预览或「预览」按钮，用当前裁剪结果打开大图。点空白、关闭按钮或 Esc 可关闭。
- 预览和导出按画面上的缩放换算回原图像素，避免只导出屏幕上那一块的分辨率。单边超过 16384 像素时按比例缩小。

## 影响范围

- `apps/web/src/pages/CropPage.vue`
- `apps/web/src/content/` 各语言文案

## 数据库与兼容性

- 无数据库影响。
- 仍在浏览器本地处理，不请求引擎。导出文件名仍是 `原名-crop.png`。

## 验证

- `npm run typecheck`：通过。
- 浏览器打开已有开发服务 `http://127.0.0.1:13175/cropping`。放入测试图后，右侧预览跟着选区、1:1 和向右旋转更新。点击预览图和「预览」按钮都会打开大图，Esc 可关闭。窄屏时预览在裁剪区下方。亮色下预览边框和棋盘格仍可见。
