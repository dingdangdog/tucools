# 怎么用上图酷的 AI 功能

抠图、优化、消除需要自己部署图酷，再另外下载模型。客户端从 [发布页](https://github.com/dingdangdog/tucools/releases) 下载标题以「TuCools Client」开头的安装包，安装后打开。Docker 下载 [项目](https://github.com/dingdangdog/tucools) 后，在项目文件夹执行 `docker compose -f deploy/docker-compose.deploy.yml up -d`，浏览器打开 http://127.0.0.1:13175 。压缩、裁剪等功能不用模型。

## 下载模型

[model-pack.zip](https://github.com/dingdangdog/tucools/releases/download/models/model-pack.zip)（约 900MB），发布页是 [models](https://github.com/dingdangdog/tucools/releases/tag/models)。

解压后应直接看到 `models` 和 `bin` 两个文件夹。如果是 `model-pack/model-pack/models`，去掉多出来的那一层。

## 模型放在哪里

放好后打开抠图、优化或消除，点「重新检查」。

**客户端**放到固定目录，目录里直接有 `models` 和 `bin`：

| 系统 | 目录 |
| --- | --- |
| Windows | `%APPDATA%\tucools\model-pack`。按 Win+R，输入 `%APPDATA%\tucools` 回车，没有 `model-pack` 就新建 |
| macOS | `~/Library/Application Support/tucools/model-pack` |
| Linux | `~/.local/share/tucools/model-pack` |

**Docker** 放到项目文件夹里，和 `deploy` 并排，不要放进 `deploy`。启动文件在 `deploy` 中，它会到上一级找 `model-pack`：

```text
tucools/
  deploy/
    docker-compose.deploy.yml
  model-pack/
    models/
    bin/
```
