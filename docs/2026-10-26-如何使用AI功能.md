# 怎么用上图酷的抠图、优化和消除

图酷里的压缩、裁剪、加水印，安装好或用浏览器打开就能用。抠图、优化、消除不一样：程序里不带现成的模型，也不会把图片送到别的网站去算。要在你自己的电脑上打开图酷，再自己下载模型，放到指定文件夹。

不用会写代码。按下面三件事做完，左侧「AI 处理」里的三个功能就可以用。没有账号，也不用登录。

## 你要做的三件事

1. 在自己的电脑上打开图酷。可以安装客户端，也可以用 Docker。两条路选一条。
2. 下载模型压缩包。客户端和 Docker 用的是同一个包。
3. 把解压出来的模型放到对应文件夹，再回到页面点「重新检查」。

| | 客户端 | Docker |
| --- | --- | --- |
| 打开方式 | 安装后出现一个叫「图酷」的窗口 | 用浏览器打开 `http://127.0.0.1:8080` |
| 模型放哪 | 系统规定的固定文件夹，不能改地方 | 项目文件夹里，和 `deploy` 文件夹并排 |
| 适合谁 | 想要一个普通软件，并且页面没有提示「引擎没有响应」 | 想用 AI、电脑上还没有图酷的处理程序 |

压缩、缩放、转格式、裁剪、水印这些不用做这三件事。证件照尺寸只是裁切和铺底色，不会抠图。AI提示词提取只是读取图片里已经写好的文字，也不用模型。

## 第一步：在自己的电脑上打开图酷

先选一种。已经打开过图酷的话，直接做第二步。

### 安装客户端

1. 用浏览器打开 [图酷的发布页](https://github.com/dingdangdog/tucools/releases)。
2. 找一个带安装文件的版本。页面上如果只有说明、没有下面这些文件，换一个版本，或者改用后面的 Docker。

| 你的电脑 | 要下载的文件 |
| --- | --- |
| Windows | 名字里有 `windows-x64`、结尾是 `.exe` |
| Mac，Apple 芯片 | 名字里有 `mac-arm64`、结尾是 `.dmg` |
| Mac，Intel | 名字里有 `mac-x64`、结尾是 `.dmg` |
| Linux | 名字里有 `AppImage` 或 `deb` |

3. 安装包没有签名，系统可能会拦截。
   - Windows 若写着未知发布者：点「更多信息」，再点「仍要运行」。
   - Mac 若打不开：打开「系统设置」，进入「隐私与安全性」，允许打开图酷。
4. 安装完成后打开「图酷」。左侧能看到「常规处理」和「信息处理」，这些现在就能用。

接着点一次「抠图」，看它怎么说：

- 写着「没有可用模型」：处理程序已经在这台电脑上。继续做第二步和第三步，把模型放进固定文件夹。
- 写着「引擎没有响应」：这台电脑还没有图酷的处理程序。公开发布的安装包不包含它。模型放对了也不会开始抠图。请改用下面的 Docker，模型仍然是同一个压缩包。

### 用 Docker 打开

Docker 下载下来的程序里已经带有处理程序。你只要再把模型放对。

先安装 Docker 的桌面版：

1. 打开 [Docker Desktop](https://www.docker.com/products/docker-desktop/)，下载和你的系统对应的安装包。
2. 按安装向导完成。Windows 如果要求安装 WSL，点同意，装完后重启电脑。
3. 打开 Docker Desktop，等到它显示正在运行。没运行起来之前，先不要做后面的启动。

再下载图酷：

1. 打开 [图酷仓库](https://github.com/dingdangdog/tucools)。
2. 点绿色的 **Code**，再点 **Download ZIP**。
3. 把压缩包解压到一个短路径，例如 `D:\tucools`。解压后要能看到一个 `deploy` 文件夹，里面有 `docker-compose.deploy.yml`。

模型还没放好也可以先启动。第一次启动会下载好几个 GB，需要一段时间，请保持网络畅通，并留出足够磁盘空间。

在 Windows 上启动：

1. 打开刚才解压的文件夹，确认看得到 `deploy`。
2. 点窗口顶部的地址栏，把里面的路径删掉，输入 `cmd`，按回车。会弹出一个黑窗口。
3. 把下面这一整行复制进去，按回车：

```text
docker compose -f deploy/docker-compose.deploy.yml up -d
```

在 Mac 或 Linux 上启动：

1. 打开「终端」。
2. 输入 `cd `，注意 `cd` 后面有一个空格，然后把解压出来的文件夹拖进终端窗口，按回车。
3. 粘贴上面同一行命令，按回车。

等到命令结束、没有红色报错，用浏览器打开：

[http://127.0.0.1:8080](http://127.0.0.1:8080)

这时压缩、裁剪已经能用。点「抠图」会提示还没有模型，这是正常的，继续做第二步。

没有 NVIDIA 显卡时，不要再加别的启动文件。加错会导致容器创建失败。没有显卡也能抠图、优化和消除，只是会慢一些。已经确认 Docker 能使用这张显卡时，才把命令换成：

```text
docker compose -f deploy/docker-compose.deploy.yml -f deploy/docker-compose.gpu.yml up -d
```

不确定的话，用第一条。

## 第二步：下载模型

客户端可以不用自己下载。打开抠图、优化或消除，模型还没放好时点「下载并安装」。程序会下载下面这个压缩包，并解压到第三步的文件夹。网页和 Docker 没有这个按钮，按下面的步骤做。

客户端和 Docker 下载同一个文件：

[model-pack.zip](https://github.com/dingdangdog/tucools/releases/download/models/model-pack.zip)

大约 900MB。打不开时，先打开 [模型发布页](https://github.com/dingdangdog/tucools/releases/tag/models)，再点页面上的 `model-pack.zip`。

下载后解压。解压结果里要能直接看到两个文件夹，名字一个是 `models`，一个是 `bin`。两个要挨在一起。

如果打开后看到的是文件夹套文件夹，例如先看到 `model-pack`，点进去才看到 `models` 和 `bin`，用里面这一层。最终拿去放置的，就是直接装着 `models` 和 `bin` 的那一层。

不要只复制 `models`。优化还要用 `bin` 里面的程序。文件名也不要改。

## 第三步：放到对应的文件夹

### 客户端：放进固定文件夹

模型必须放在系统指定的位置。放在安装目录、桌面或「下载」里，图酷不会去读。

放好以后，这个文件夹里面应当直接有 `models` 和 `bin`，不能再多包一层。

**Windows**

1. 按 `Win + R`。
2. 输入下面这一行，按回车：

```text
%APPDATA%\tucools
```

3. 如果提示找不到文件夹：再按 `Win + R`，只输入 `%APPDATA%` 并回车。在打开的文件夹里新建一个文件夹，名字写成 `tucools`。
4. 进入 `tucools`。如果没有 `model-pack`，就新建一个，名字必须是 `model-pack`。
5. 把第二步准备好的 `models` 和 `bin` 放进 `model-pack`。

放好后的位置类似：

```text
C:\Users\你的用户名\AppData\Roaming\tucools\model-pack\models
C:\Users\你的用户名\AppData\Roaming\tucools\model-pack\bin
```

**Mac**

1. 打开访达。
2. 按 `Command + Shift + G`。
3. 粘贴下面这一行，按回车：

```text
~/Library/Application Support/tucools
```

4. 如果没有这个文件夹，先到 `~/Library/Application Support`，新建 `tucools`。
5. 在 `tucools` 里新建 `model-pack`，把 `models` 和 `bin` 放进去。

**Linux**

打开主文件夹，进入 `.local`，再进入 `share`，再进入 `tucools`。没有就逐层新建。最后在 `model-pack` 里放上 `models` 和 `bin`。

`.local` 是隐藏文件夹。文件管理器里按 `Ctrl + H` 可以显示隐藏文件。

### Docker：放在项目文件夹里，和 deploy 并排

启动文件在 `deploy` 文件夹里面。模型不要放进 `deploy`，也不要和 `docker-compose.deploy.yml` 放在同一个文件夹。程序会到 `deploy` 的上一级找一个名叫 `model-pack` 的文件夹。

假设你把图酷解压到了 `D:\tucools`，放好后应是这样：

```text
D:\tucools\
  deploy\
    docker-compose.deploy.yml
  model-pack\
    models\
    bin\
```

`model-pack` 和 `deploy` 是邻居。`models` 和 `bin` 在 `model-pack` 里面。

页面上如果出现 `/model-pack`，那是程序内部看到的位置，不是你电脑上的盘符。不要在 Windows 里寻找一个叫 `/model-pack` 的磁盘目录。

模型是在启动之后才放进去的话，回到黑窗口或终端，在同一个文件夹里再执行一次原来的启动命令。然后继续下面的检查。

## 放好后怎么确认

回到图酷，打开「抠图」「优化」或「消除」，点「重新检查」。

可以开始时，红色提示会消失，图片能拖进画面：

- 抠图的右侧出现「模型」，里面是已经放好的效果。
- 优化的右侧出现「效果」和「倍率」。
- 消除可以在图片上涂抹。

还不行时，对照页面上的原句：

| 页面上的话 | 含义 | 怎么做 |
| --- | --- | --- |
| 引擎没有响应 | 处理程序没启动 | 客户端改用 Docker。Docker 则确认 Docker Desktop 正在运行，并重新执行启动命令 |
| 没有可用模型，这个功能已停用 | 文件夹空的、放错了，或多套了一层 | 按上面的文件夹图重新放，再点「重新检查」 |
| 还缺这些文件 | 页面会列出缺的文件名 | 把列出的文件放进 `models` 或 `bin` 里对应的位置 |
| 还有部分模型未安装 | 缺的那几种效果不能用，已经放好的可以 | 可以先用现有效果，也可以把缺的文件补上 |

三个功能可以分开可用。抠图只要五种模型里有一种就能处理；优化和消除各自检查自己的文件。

## 三个功能怎么用

一次只处理一张图，单张不要超过 50MB。正在处理时，等这一张结束再放下一步。图片只发给你这台电脑上的图酷，不经过其他网站。

**抠图**

1. 左侧点「抠图」。
2. 把图片拖进画面，或点「选择文件」。
3. 在「模型」里选一种：通用、轻量、人像、高精度、动漫。人像选「人像」，动漫图选「动漫」，拿不准就选「通用」。
4. 点「开始抠图」。
5. 完成后点「下载结果」。得到的是透明背景的 PNG。

**优化**

1. 左侧点「优化」。
2. 放入图片。
3. 选「效果」：通用增强、标准增强、高质量增强、数字艺术、动漫。
4. 选「倍率」。倍率越大，图片越大，等待也越久。
5. 点「开始优化」，再点「下载结果」。

没有显卡时这一步会比较慢，让它跑完即可。

**消除**

1. 左侧点「消除」。
2. 放入图片。
3. 用鼠标在要去掉的路人、文字或杂物上涂抹。右侧可以调「画笔粗细」。涂过的地方会留下半透明笔迹。
4. 涂错了点「清除涂抹」，再涂一次。
5. 点「开始消除」，再点「下载结果」。

## 常见问题

### 解压后不知道该拿哪一层

一直点进去，直到同一个文件夹里同时有 `models` 和 `bin`。把这两个文件夹放进目标位置。如果目标里变成 `model-pack\model-pack\models`，说明多了一层，把里面的 `models` 和 `bin` 上移一层。

### 优化不能用，抠图可以

优化除了模型，还要 `bin` 里的程序。请确认整个 `bin` 文件夹都在。Docker 使用的是其中的 Linux 程序，所以不要只留下 Windows 的程序。

### 客户端放进了安装目录

安装目录不是模型目录。Windows 用 `Win + R`，输入 `%APPDATA%\tucools`，模型要在这里面的 `model-pack`。页面上「解压到这个目录后再检查」后面写的路径，就是要放的位置。

### Docker 把模型放进了 deploy

那样找不到。把 `model-pack` 挪到 `deploy` 的旁边，再执行一次启动命令，然后点「重新检查」。

### 浏览器打不开 127.0.0.1:8080

先看 Docker Desktop 是不是正在运行。再到解压文件夹重新执行启动命令。命令还在下载或报错时，页面不会打开。地址要带 `http://`，端口是 `8080`。

### 处理很慢

没有显卡时使用 CPU，优化尤其久。一次只处理一张。不要同时开很多个任务。

### 想关掉 Docker 里的图酷

在解压文件夹打开以前那个黑窗口或终端，执行：

```text
docker compose -f deploy/docker-compose.deploy.yml down
```

这只停止图酷，不删除你放好的模型。下次想用，再执行原来的 `up -d` 命令。
