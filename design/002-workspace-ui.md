# 图酷工作台界面

## 1. 目标与约束

- 用户在本机安装包或浏览器里连续处理图片。主任务是选工具、放入图片、调整、看结果、保存。
- 同一份 `apps/web` 给 Docker 和 Windows 安装包用。本地工具不上传。抠图、优化、消除只走 `/api/engine`。
- 配色继续用石板亮色、中性黑暗色和蓝色强调。未保存主题时默认暗色。
- 不做营销页、页脚、FAQ、激活、试用和支付。

## 2. 设计方向

界面是工业实用的图像工作台。画面占主区域，控件靠在旁边。中性色承担结构，蓝色只用于当前项和主操作。工具色只出现在首页和侧栏的小图标上。

原则：

1. 先看见图片或拖放区，再看见设置。
2. 同一类动作用同一种按钮。主操作在面板底部或结果区。
3. 明暗两套都要能看清描边、输入框和透明图。

## 3. 页面结构

- 外壳：240px 侧栏，图标加名称，分组为本地处理和 AI 处理。顶栏是当前工具名和主题切换。窄屏侧栏收进抽屉。
- 首页：工具卡，小色块图标、名称、一句说明。
- 单图工作台：裁剪、证件照尺寸、社交尺寸、水印、加字、抠图、优化、消除。左侧画面区撑满剩余高度，右侧约 320px 设置。窄屏改为上图下设置。
- 批量工作台：压缩、缩放、转格式、切图、灰度、圆形、去除信息、图转 PDF、Favicon、嵌入提示、图片信息。上方是说明和芯片或紧凑字段，没结果时拖放区拉高，有结果后显示预览、尺寸和体积。

抠图和优化在处理完成后用可拖动的前后对比。消除的涂抹层对齐画面里的图片。水印和加字在画面上即时预览，导出仍走原来的绘制函数。裁剪比例为自由、1:1、4:3、3:2、16:9、9:16。

## 4. 视觉系统

令牌在 `apps/web/src/styles.css`。组件使用变量，不写死颜色。

- 表面：页面底、侧栏、面板、画面底、描边、主文字、次文字、强调、危险。
- 透明图用棋盘格。
- 控件圆角 8px，画面和面板 12px。阴影只用于对比手柄。
- 按钮、输入、芯片、滑杆是共用类。
- 图标来自 `@heroicons/vue` 线框图标。导航和主按钮保留文字。

## 5. 组件

| 组件 | 用途 |
| --- | --- |
| `StudioLayout` | 单图工作台，画面加侧栏 |
| `BatchLayout` | 批量工作台 |
| `Stage` | 整区拖放或预览，处理中盖住画面 |
| `Chips` | 少选项的单选或多选 |
| `CompareView` | 左右拖动对比，可用方向键 |
| `ResultGrid` | 结果预览、说明、下载 |
| `EngineStatus` | 引擎是否就绪 |

`useResults().add` 可以带上可选的体积或尺寸说明。

## 6. 响应式与可访问性

- 桌面侧栏常驻，窄屏用「工具」打开抽屉。
- 主按钮高度约 44px。图标按钮有名称。
- 焦点用蓝色轮廓。对比滑杆可键盘操作。
- 减少动效时关掉过渡。

## 7. 不改的部分

路由、本地算法、引擎参数、保存路径不变。模型包、安装包和两个旧项目不改。
