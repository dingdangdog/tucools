# 工具页右侧广告与常见问题

## 目标

工具页把图片、选项和按钮放在左侧。右侧上方是广告，下方是常见问题。未配置广告时不留广告区。页头的手机菜单只用图标。页头提供 GitHub 仓库链接。

同一份页面继续给 Docker 和 Windows 安装包使用。默认不加载广告。

## 布局

- 外壳锁在视口高度。左侧菜单保持视口高度，只在菜单内部滚动。主体过高时只滚动主体，不把菜单和整页一起撑高。
- 宽屏（`lg` 及以上）：左侧功能区独立滚动，右侧约 320px。广告在上，常见问题在下并在栏内滚动。
- 窄屏：先是功能区，再是广告和常见问题，这几块在主体区域内滚动。
- 从右到左的页面沿用同一行方向，主区域在阅读起点，广告和常见问题在末侧。
- 首页和功能菜单仍是整页，不使用这栏。

单图工具的左侧顺序是说明、画面、选项、按钮。宽屏时画面占用剩余高度，选项过高时在选项区内滚动。批量工具的左侧是说明和按钮、选图、选项、结果。选图在选项上面；有选项时选图区固定高度，没有选项时选图区继续拉高。

## 广告

发布商编号和广告单元都在运行时读取，不写进构建结果。

| 变量 | 作用 |
| --- | --- |
| `TUCOOLS_ADSENSE_CLIENT` | 发布商编号。合法时写入 `/ads.txt`，加载 `adsbygoogle.js`，并加入 `google-adsense-account`。 |
| `TUCOOLS_ADSENSE_SLOT` | 可选。展示广告单元编号。与发布商编号同时合法时，工具页右侧显示这个单元。 |

`ads.txt` 固定为 `google.com, pub-数字, DIRECT, f08c47fec0942fa0`。编号只接受数字，避免把环境变量拼进脚本地址。只配置发布商编号时，自动广告仍可能由 AdSense 自行放置，右侧不留空位。

广告位是 AdSense 的 `<ins class="adsbygoogle">` 占位，`data-ad-format="auto"`、`data-full-width-responsive="true"`。不包卡片，不写「广告」标题，不设最小高度。宽度跟随右侧栏，高度由广告脚本决定。

开发服务器、页面容器和安装包静态服务都读这两个变量。容器改完后重新创建即可，不必重新构建镜像。
