# 011 客户端下载模型包

## 目标

客户端在模型还没放好时，直接下载 `model-pack.zip` 并解压到本机模型目录。网页和 Docker 仍只打开发布页。

## 非目标

- 不把模型包打进安装包或镜像。
- 不在打开应用时自动开始下载。约 900MB，由使用者点击「下载并安装」。
- 不校验发布文件的哈希。发布页目前没有随包校验值。
- 不改引擎的健康检查契约。放好文件后重新检查即可，不必重启引擎。

## 做法

下载地址固定为 `https://github.com/dingdangdog/tucools/releases/download/models/model-pack.zip`。页面不能改这个地址。

Electron 主进程下载到临时目录，再按中央目录解压。只接受存储和 deflate。拒绝加密、符号链接、绝对路径和 `..`。解压结果里找到同时包含 `models` 和 `bin` 的那一层，只把这两个目录复制到 `modelPackDir`。外层如果多包了一层 `model-pack`，会剥掉。macOS 和 Linux 上给 `bin` 里的文件加上可执行权限。

同一时间只下载一个包。可以取消。失败时不改已有模型目录；复制开始之后如果磁盘写失败，目录里可能有一部分新文件，再点一次会覆盖。

页面用 `window.tucools.downloadModelPack` 判断是不是客户端。没有这个方法时，仍显示原来的发布页链接。
