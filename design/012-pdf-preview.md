# 图转 PDF 页面预览

## 1. 目标

图转 PDF 在导出前就能看到每一页。纸张、方向、放入方式、页边距、底色和页面顺序改了，预览跟着变。生成仍在浏览器本地完成，不上传。

## 2. 页面

- 没放图片时，主区域是拖放区，下面是纸张设置。
- 放入后，主区域左侧是页面缩略图，中间是当前页。窄屏改为上面大图、下面横排缩略图。
- 缩略图可以拖动排序，也可以前移、后移、旋转和移除。继续拖入或点「添加图片」会接到末尾。
- 大图下面写出当前页码和纸张的毫米尺寸。
- 「生成 PDF」按当前预览导出一个文件。文件名用第一张图片的主文件名。

## 3. 排版

默认 A4、方向随图片、留白完整显示、无页边距、白底。横图会换成横向纸张，整张图都留在页内。

纸张还有 A3、A5、Letter 和原比例。原比例的页面跟图片同形，长边等于 A4 长边，也就是 297 毫米。页边距按较短边的百分比向内收，最大 20%。铺满会裁掉超出的部分，拉伸会改变图片比例。透明区域用所选底色铺上。

预览和导出使用同一套页面几何。导出把每一页画成 JPEG，长边按 150 DPI，不超过 4096 像素，再放进对应尺寸的 PDF 页。

## 4. 不改的部分

仍然每张图片一页，不请求引擎，不上传。其他工具的拖放区高度不变。
